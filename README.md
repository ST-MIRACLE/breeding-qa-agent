# 番茄育种智能决策系统 (Tomato Breeding Intelligence System)

基于 RAG（检索增强生成）的育种知识库问答系统，面向育种科研人员，解决大量种质实验数据人工整理耗时长、知识检索困难、决策缺乏依据的痛点。

> 项目背景：作者为农学硕士，在读研期间深感应育种团队缺少一个"能用自然语言查数据、问知识"的工具——数据散落在几十个 Excel、知识分散在文档里，找人问很慢。本项目从自身真实痛点出发独立完成。

## 核心能力

- **抗病基因知识问答** — 覆盖 Ty1/Ty2/Ty3/Tm-2a/SW/ToBRFV 等 11 种抗病基因，支持遗传方式、连锁关系、育种应用等深度查询
- **育种数据智能查询** — 自然语言查询 Excel 育种数据，支持糖度/硬度/果重筛选、TOP 排名、均值统计、多季节对比
- **基因型筛选** — 识别抗病/感病/杂合（R/H/S），按材料聚合统计（如"25年第二批回交材料 Ty 抗病材料有哪些"）
- **图表可视化** — 一键生成基因型分布饼图（如"把252的Ty1抗感杂合做成饼图"），输出 HTML 图表
- **季节品质报告生成** — 一键生成 252/261 等多季品质分析报告，含均值/极值/TOP5/分布统计
- **杂交组合推荐** — 基于抗病基因聚合 + 性状互补原则，结合分子标记数据，智能推荐最优杂交组合
- **意图分类与寒暄兜底** — 5 类意图自动路由；"你是谁"等寒暄问题直接返回固定欢迎语，不浪费算力
- **API 容错降级** — LLM API 不可用时自动降级为本地检索模式，保证系统始终可用

## 技术架构

```
用户提问 → 寒暄识别 → 意图分类(5类) → 多源检索(TF-IDF + 结构化知识库 + Pandas数据) → LLM生成/本地降级 → 回答
```

| 模块 | 技术 | 说明 |
|------|------|------|
| RAG 引擎 | Python | 意图分类 + 混合检索 + LLM 生成 + 报告生成 + 图表生成 |
| 检索引擎 | NumPy (TF-IDF) | 纯 NumPy 实现，零外部依赖，适合垂直小领域 |
| 结构化检索 | 关键词精确匹配 | JSON 结构化知识库（基因/遗传/标准）精确命中 |
| 数据查询 | Pandas | Excel 育种数据读取、条件筛选、精确计算 |
| LLM | Qwen-Plus (DashScope) | 兼容 OpenAI 格式；API 不可用时自动降级为本地检索 |
| 图表 | ECharts | 本地加载，离线可用 |
| Web 界面 | HTML + JS | 暗色主题聊天界面 |

## 快速开始

```bash
# 1. 安装依赖
pip install pandas openpyxl requests numpy

# 2. 配置 API Key
cp config.example.json config.json
# 编辑 config.json 填入你的 DashScope API Key

# 3. 放入育种数据（可选，用于数据查询/报告生成/杂交推荐）
# 将品质测定、性状调查等Excel文件放入 data/ 目录，系统启动时自动加载

# 4. 启动系统
python src/chat_server.py
# 或双击 启动.bat
```

浏览器自动打开聊天界面，输入问题即可获得育种知识解答。

## 意图分类（5 类）

系统自动识别用户意图，路由到不同检索通道：

| 意图 | 触发关键词 | 处理逻辑 |
|------|-----------|----------|
| greeting | "你是谁""你能做什么""你好" | 返回固定欢迎语，不走检索 |
| chart_query | "饼图""图表""可视化""分布图" | 统计基因型分布并生成 ECharts 饼图 |
| report_query | "生成报告""分析报告""品质分析" | 汇总指定季节的品质/性状数据 |
| data_query | "糖度大于X""TOP""排名""筛选""抗病材料" | Pandas 条件查询 Excel 数据 |
| hybrid_query | "杂交组合""推荐""配组""选配" | 基于基因聚合+性状互补推荐 |
| knowledge_query | 其他 | TF-IDF + 结构化知识库检索 |

## 数据查询能力

- **季节解析**：支持 252/261 代号、"25年/26年"、"2025年/2026年"等多种说法
- **条件词解析**：支持 大于/高于/超过/以上/不少于/不低于/小于/低于/以下/不超过/不高于
- **基因型查询**：识别 ty1/ty2/ty3/tm-2a 等基因 + 抗病(R)/感病(S)/杂合(H)，按材料去重聚合统计
- **数据规范化**：将"无/无带/无条带"及空值统一归为"无条带"，避免分类模糊

## 技术亮点

- **TF-IDF 纯 NumPy 实现** — 检索引擎零外部依赖，适合离线场景
- **三路检索融合** — 结构化知识库（精确匹配）+ 非结构化文档（TF-IDF）+ Pandas 数据查询（精确计算），针对不同数据形态用最合适的检索方式
- **双模态容错** — API 模式（LLM 综合分析）+ 本地模式（知识库检索直出）
- **RAG 知识库约束** — system prompt 强制"只基于知识库内容回答+标注来源"，杜绝 LLM 幻觉
- **意图分类 + 寒暄兜底** — 非业务问题直接返回固定欢迎语，避免答非所问、节省 token
