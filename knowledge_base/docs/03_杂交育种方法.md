# 番茄杂交育种方法与组合选配原则

## 杂交亲本选配原则

### 1. 性状互补原则
- 亲本性状应互补，一方优势弥补另一方劣势
- 示例：亲本A高糖（糖度12）但抗病差（0个抗病基因），亲本B抗病好（Ty1+Ty3+Tm-2a）但糖度低（糖度8）
- 预期：后代可能出现高糖+多抗的重组类型
- 注意：数量性状（如糖度）后代偏向中间型，需在F2或以后世代选择超亲个体

### 2. 抗病基因聚合原则
- 优先选择携带不同抗病基因的亲本配组
- 后代可能聚合多个抗病基因，实现广谱抗性
- 示例：亲本A携带Ty1+Ty3，亲本B携带Tm-2a+Sw-5b → 后代可能获得Ty1+Ty3+Tm-2a+Sw-5b的多抗组合
- 杂合（H）标记的亲本后代会分离，需在后代继续分子标记筛选

### 3. 避免近缘原则
- 亲本间亲缘关系不宜过近，避免近交衰退
- 检查亲本系谱，确认无共同亲本
- 近交衰退表现：长势减弱、抗性下降、产量降低
- 建议：使用不同育种来源的材料配组，增加遗传多样性

### 4. 目标导向原则
- 围绕育种目标选择亲本
- 当前目标：多抗病毒病（Ty1+Ty3+Tm-2a）+ 高糖（≥10）+ 好吃（喜好度≥7）
- 至少一方亲本应满足糖度要求
- 至少一方亲本应携带目标抗病基因
- 感官品质需要双方都有较好表现

### 5. 杂合状态处理
- 杂合（H）标记的亲本后代会发生分离
- R×H → 后代1/2R，1/2S
- H×H → 后代1/4R，1/2H，1/4S
- 建议：尽量选择纯合（R）的亲本，减少后代筛选工作量

## 杂交后代选择方法

### 系谱法
- 从F2开始单株选择，每代系谱记录
- F2群体要大（至少200株），增加重组机会
- F3-F4开始关注主要性状
- F5-F6固定后进行品比试验

### 分子标记辅助选择（MAS）
- 在苗期即可检测抗病基因型
- 可同时检测多个抗病基因
- 大幅缩短育种周期，减少田间种植面积
- 建议在BC1F1或F2代开始MAS筛选

### 多代回交策略
- 用于将抗病基因导入优良品种
- BC1F1检测标记 → 选择携带目标基因的个体回交
- BC2F1再次检测 → 继续回交
- BC3F1自交获得BC3F2 → 筛选纯合个体
- 每代回交后需检测目标基因是否保留

## 杂交组合评价方法

### 田间评价
- F1代评价配合力（一般配合力GCA和特殊配合力SCA）
- 观察F1的优势表现（杂种优势）
- 重点关注目标性状（糖度、抗病、感官）

### 室内评价
- 分子标记检测抗病基因型
- 品质测定（糖度、硬度、果重等）
- 感官评价（色泽、口感、汁水等7个维度）

### 数据分析
- 配合力分析：评估亲本的利用价值
- 杂种优势分析：计算中亲优势和超亲优势
- 性状相关性分析：发现性状间的关联
